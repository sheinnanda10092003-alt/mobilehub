MobileHub E-Commerce System

Deployment Diagram - Three-Tier Architecture

Component Legend

Client Devices: User devices with web browsers
Firewall: Network security and traffic filtering
Web Server: Apache with PHP and Laravel application
Database Server: MySQL relational database
External Services: Third-party integrations

Deployment Notes

  • Three-Tier Architecture: Separation of presentation, application logic, and data storage
  • Communication Protocol: All tiers communicate via TCP/IP with HTTPS encryption for client-server communication
  • Security: Multi-layered security including firewall, HTTPS/TLS, Laravel's built-in security features (CSRF, XSS protection)
  • Database: MySQL 8.0 with 13 tables handling users, products, orders, inventory, and purchases
  • Framework: Laravel 12 with MVC architecture, Eloquent ORM, Blade templating, and middleware pipeline
  • Scalability: Can be scaled horizontally (multiple servers) or vertically (better hardware)
